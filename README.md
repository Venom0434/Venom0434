# Shakti Plastic Industries (TSPI) Website

This repository contains a professionally designed website for Shakti Plastic Industries. The website is built with modern HTML5, CSS3, and JavaScript to provide a responsive and user-friendly experience.

## 🌟 Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, professional design with smooth animations
- **SEO Optimized**: Proper HTML structure and meta tags for search engine optimization
- **Interactive Elements**: Contact form, smooth scrolling navigation, and mobile menu
- **Cross-browser Compatible**: Works on all modern browsers
- **Fast Loading**: Optimized CSS and JavaScript for quick page loads

## 📁 Project Structure

```
├── index.html          # Main HTML file
├── styles.css          # Complete stylesheet
├── script.js           # JavaScript functionality
└── README.md          # Project documentation
```

## 🚀 Getting Started

1. **Clone or download** this repository
2. **Open `index.html`** in your web browser
3. **Customize the content** as needed (see customization guide below)

## 🎨 Customization Guide

### Updating Content

Since the original website (https://www.shaktiplasticinds.com/tspi/) was not accessible during development, placeholder content has been used. To update with actual content:

#### 1. Company Information
- Update company name, tagline, and description in `index.html`
- Replace placeholder contact information (address, phone, email)

#### 2. Images
- Replace placeholder images with actual company photos
- Update image alt text for accessibility
- Recommended image sizes:
  - Hero image: 600x400px
  - Product images: 300x200px
  - About section image: 500x300px

#### 3. Colors and Branding
In `styles.css`, update the color scheme:
```css
/* Primary brand colors */
--primary-color: #3498db;    /* Main brand color */
--secondary-color: #2c3e50;  /* Dark text color */
--accent-color: #27ae60;     /* Success/accent color */
```

#### 4. Content Sections
- **Hero Section**: Update main headline and description
- **About Section**: Add actual company history and features
- **Products Section**: Replace with real products and descriptions
- **Services Section**: Update with actual services offered
- **Contact Section**: Add real contact information and address

### Advanced Customization

#### Adding New Sections
1. Add HTML structure in `index.html`
2. Add corresponding styles in `styles.css`
3. Update navigation menu if needed

#### Integrating Contact Form
The contact form currently shows an alert. To make it functional:
1. Set up a backend endpoint (PHP, Node.js, etc.)
2. Update the form submission handler in `script.js`
3. Add proper server-side validation
